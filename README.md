# Student Management System (SQL + MySQL)

Project Overview
This project is a Student Management System built using MySQL to demonstrate core database concepts such as relational design, data manipulation, and data analysis using SQL. The system manages student records, subjects, and marks in a structured relational format.

---
Database Structure
The database consists of three related tables:

* **Students**: Stores student personal and academic details
* **Subjects**: Stores subject information
* **Marks**: Stores marks obtained by students in different subjects

Primary and foreign key constraints are used to maintain data integrity.

---
Features
* Relational database design with normalized tables
* CRUD operations using SQL queries
* Multi-table joins to generate combined datasets
* Aggregate functions for academic performance analysis
* Indexing to improve query performance
* SQL view creation for reusable joined datasets

---
SQL Concepts Used
* CREATE DATABASE and CREATE TABLE
* PRIMARY KEY and FOREIGN KEY
* INSERT, SELECT, UPDATE, DELETE
* INNER JOIN
* WHERE and GROUP BY clauses
* Aggregate functions (AVG, MAX)
* INDEX
* VIEW

---
Sample Output
The project generates:
* Student-wise subject marks
* Average marks per student
* Highest marks per subject
* Filtered results based on conditions

---
How to Run
1. Open MySQL Workbench or any MySQL client
2. Execute the SQL script provided in the repository
3. Run the SELECT queries to view the results
